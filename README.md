# StretchClock17 0.1.1

Fixed Lock Screen clock stretching for rootless iOS 17. Default scales are 122% width and 165% height, subject to available space. Tested on iPhone 15 Pro Max, iOS 17.1.1, and Dopamine.

Install the release package in Sileo and respring. Build from source with Theos and an iOS SDK using `make package FINALPACKAGE=1`.
