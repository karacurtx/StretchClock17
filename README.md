# StretchClock17

Твик для экрана блокировки на iOS 17 со стандартным rootless-джейлбрейком. В разделе «Настройки → StretchClock17» можно выбрать высоту от 100 до 220% и ширину от 100 до 160%. Начальные значения 165% по высоте и 122% по ширине. Размер ограничивается доступной областью. Цвет, шрифт и формат времени берутся из текущего оформления iOS.

Изменения применяются при следующей отрисовке экрана блокировки. Автоподстройка под объект на фото, эффект Liquid Glass и переразметка виджетов и уведомлений пока отсутствуют.

## Сборка и установка

Для сборки обеих архитектур используйте [Theos на macOS с Xcode](https://theos.dev/docs/installation-macos) и настроенным iOS SDK. Для ARM64E нужен совместимый линкер, подробнее в [документации Theos по rootless](https://theos.dev/docs/rootless).

В распакованной папке проекта выполните:

```sh
make package FINALPACKAGE=1
```

Откройте `.deb` из папки `packages/` на iPhone через Sileo или Zebra, установите и сделайте respring. Для первой проверки лучше выбрать экран блокировки без виджетов под временем. Затем проверьте, как часы выглядят с виджетами, уведомлениями и после повторной блокировки. Для отката удалите StretchClock17 в пакетном менеджере и сделайте respring.

Sileo установит зависимость PreferenceLoader, если её ещё нет. Если «Настройки» были открыты во время установки, закройте их и откройте снова после respring.

Точки подключения сверены с [исходником LSTimeSeconds-iOS17](https://github.com/Chenlin8023/LSTimeSeconds-iOS17/blob/master/LSTimeSeconds.xm). Тестовый пакет для iPhone 15 Pro Max, iOS 17.1.1 и Dopamine содержит бинарник arm64e. Работа на iPhone ещё не проверена.
